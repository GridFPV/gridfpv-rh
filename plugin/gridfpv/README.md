# GridFPV plugin for RotorHazard

Copy this `gridfpv/` folder into RotorHazard's user plugins directory (usually
`~/rh-data/plugins/`) and restart RotorHazard. The UI is at `http://<timer>/grid`.

Requires RotorHazard 4.4.0 or newer. Source, issues and releases:
https://github.com/GridFPV/gridfpv-rh
