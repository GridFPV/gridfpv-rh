# Pilots

Callsign is what the announcer says; name, phonetic spelling, team and colour are
optional. **New pilot** writes nothing until **Save**. Plugin attributes RotorHazard knows
(a MultiGP id, for example) are fields on the same dialog.

A double quote in a callsign is kept here and in the results, but RotorHazard's own
Format page cuts the name at it; avoid it if you edit pilots there.

## The roster

Pilots outlive events. Every pilot added or edited here joins the roster, a file GridFPV
keeps beside RotorHazard's database that survives a new event. **Add from roster** lists
everyone from earlier events who is not in this one; tick who is racing today. **Forget**
drops someone from the roster for good (they stay in any event they are in).

## Deleting

A pilot who flew a saved race cannot be deleted: RotorHazard keeps them for the results.
Unseat them instead.
