# Teams

Teams are names GridFPV keeps and pushes into RotorHazard's own pilot dropdown, so both
UIs offer the same list. A pilot's team is set on the Pilots page.

- **Rename** moves the team's pilots to the new name.
- **Delete** leaves its pilots with no team.

Team racing itself is a format setting (Formats page, Racing mode): RotorHazard then
scores by team in the results.
